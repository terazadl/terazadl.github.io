# 中日政经周报撰写规范与模板指南（Editorial & Template Guide）

> 本指南供作者与撰写模型统一周报写作标准。  
> 对应需求：R1（统一模板）、R2（中日对照）、R3（数据雷达）、R4（主线一图）、R6（篇幅与纪律）、R7（观测站联动）。

---

## 1. 结构与排版纪律（R1, R6）

周报必须严格按照以下统一层级输出，不得随意调换章节次序：

1. **Front-matter**：必须包含 `series` (`japan-weekly` 或 `china-weekly`), `week_start`, `week_end`, `mainline`, `compare_one_liner`。
2. **覆盖范围导语**：标明时区、起始与截止时间戳，申明仅收录当周新增或实质进展。
3. **## 本周主线**：1–2 句提炼核心宏观/制度矛盾。
4. **本周主线一图（可选，R4）**：日本优先提供「政策三角」SVG 图，中国优先提供「信用/流程重构」图，附单句传播句。
5. **## 核心事件（R6）**：
   - **严格数量限制**：必须为 **5–7 条**，按重要性排序。
   - **状态标签枚举**：`已确认` / `执行细节待定` / `媒体线索` / `情景判断`。
   - **四段式结构**：
     - `发生了什么（事实）`
     - `为什么重要（分析判断）`
     - `接下来关注什么`
     - `来源：[名称](链接)`
   - **事实与判断严格分栏**：严禁将作者推论伪装为既成事实；严禁将流动性平抑等同于降息信号，严禁将总量改善推论为全面回暖。
6. **## 数据雷达（R3）**：必须使用固定指标集，单位与前值跨期一致。
7. **## 中日对照（R2）**：3–5 个对照点（货币、财政、产业、居民、外部）。
8. **## 一条结构性判断**：≤150 字，非投资建议。
9. **## 下周观察清单**：2–4 条，格式为 `日期 · 事件 · 为什么看`。
10. **## 口径与来源说明（R7）**：注明权威数据源与免责声明，包含软链至 `/event-radar/`。

## 2. 固定指标雷达集（R3）

### 日本固定指标集（6–8 个）
1. **东京 CPI（总项同比）**
2. **东京 CPI（除生鲜食品及能源同比）**
3. **企业服务价格（同比）**
4. **失业率 / 有效求人倍率**
5. **10 年期 JGB 收益率（%）**
6. **USDJPY 汇率**
7. *可选本周附加*：国债费概算要求、日经 225 等

### 中国固定指标集（6 个）
1. **规上工业利润 / 工业增加值（累计同比）**
2. **固定资产投资 / 民间投资（同比）**
3. **房地产销售面积 / 投资降幅**
4. **货币姿态标签**：`稳流动性` / `出现价格信号` / `观察中`（枚举值）
5. **结构分化指示**：强行业 vs 弱行业（如电子 vs 汽车）
6. **LPR 状态**：维持不变 / 调整及基点数

## 3. 中日对照写作原则（R2）

- **顶部一句话金句 (`compare_one_liner`)**：例如 `“中国重定价信用规则，日本重定价利率与财政成本。”`
- **固定比较轴向**：
  - **货币**：央行姿态、基准利率与流动性调控。
  - **财政**：支出压力、国债发债与地方/利息负担。
  - **产业**：技术自主、绿色转型与分化趋势。
  - **居民**：可支配收入、体感温度与消费储蓄倾向。
  - **外部**：汇率走势、外贸顺差与地缘外部冲击。

## 4. 观测站（Polymarket）打通说明（R7）

若周报核心事件涉及市场定价概率（如日银加息概率、美联储降息概率等）：
- 正文须使用客观表达，并加入指向观测站的引导文本：  
  *“具体概率定价与结算规则可参考站内 [Polymarket 观测站](/event-radar/) 的实时/日报读数卡。”*
